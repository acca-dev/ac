# My List — ซื้อของ & งาน

เวอร์ชันแรกเป็นเว็บแอปแบบ static:
- รายการซื้อ
- งาน
- ปฏิทิน
- ค้นหา/กรอง
- บันทึกข้อมูลด้วย localStorage
- รองรับมือถือ
- มี PWA manifest เบื้องต้น

## เปิดใช้งานในเครื่อง
ดับเบิลคลิก `index.html` เพื่อทดลองได้ทันที

## ฝากฟรีที่ Vercel
1. สร้างบัญชี GitHub
2. สร้าง repository ใหม่ เช่น `my-list`
3. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
4. เข้า Vercel และเลือก Add New Project
5. Import repository `my-list`
6. Framework เลือก Other/Static หากระบบถาม
7. Deploy

## หมายเหตุสำคัญ
ตอนนี้ข้อมูลเก็บใน browser เครื่องนั้นเท่านั้น ถ้าเปิดมือถืออีกเครื่องจะไม่เห็นข้อมูลเดียวกัน
ขั้นต่อไปคือเชื่อม Supabase เพื่อเก็บข้อมูลออนไลน์และทำ Login/Sync
